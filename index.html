Cara Pasang / Install ke HP (PWA)

        
    
          
  1. Buka web ini di Google Chrome (Android) atau Safari (iPhone).
    2. 
          
  2. Di Android: Klik tombol "Install ke HP" di pojok kanan atas, atau ketuk tombol menu (titik 3) lalu pilih "Tambahkan ke Layar Utama" / "Install Aplikasi".
    3. 
          
  3. Di iOS (iPhone): Ketuk tombol Share (ikon kotak panah ke atas) di Safari, lalu pilih "Add to Home Screen" (Tambahkan ke Layar Utama).
    4. 
          
  4. Aplikasi akan terpasang di HP Anda seperti aplikasi bawaan (native app) tanpa address bar browser dan dapat dibuka secara offline!
    5. 
        


        
Daftar Pinout GPIO Hardware ESP32:

        

          
• GPIO 16 : Lampu Teras Depan (Relay 1)

          
• GPIO 17 : Lampu Ruang Tamu (Relay 2)

          
• GPIO 27 : Kipas Ruang Tamu (PWM / Driver Kipas)

          
• GPIO 18 : Lampu Ruang Keluarga (Relay 3)

          
• GPIO 32 : Kipas Ruang Keluarga (PWM)

          
• GPIO 19 : Lampu Kamar 1 Utama (Relay 4)

          
• GPIO 21 : Lampu WC 1 Dalam Kamar (Relay 5)

          
• GPIO 22 : Lampu Kamar Tidur 2 (Relay 6)

          
• GPIO 23 : Lampu Kamar Tidur 3 (Relay 7)

          
• GPIO 25 : Lampu Dapur (Relay 8)

          
• GPIO 33 : Kipas Dapur (PWM)

          
• GPIO 26 : Lampu WC 2 Luar / Umum (Relay 9)
